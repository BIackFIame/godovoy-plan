# Защита локального профиля в 0.5.41

Профиль содержит календарь, секрет рабочего пространства и настроенные учётные данные интеграций. Приложение проверяет права при открытии, а также перед записью резервной копии и восстановлением. Для обмена с коллегой предназначен зашифрованный файл `.yrplan`. Резервные копии в `backups` содержат ключ пространства. Сохранённый перед восстановлением исходный файл также может содержать токены API.

## Windows

Приложение создаёт новую папку профиля на локальном NTFS-диске с закрытым наследуемым списком доступа для текущего пользователя, SYSTEM и администраторов. Старую папку и её файлы оно проверяет перед открытием. Проверка охватывает отдельные разрешения на файлах, резервные копии, наследование, владельца, подменяемые родительские каталоги и точки повторной обработки.

Если проверка отклонит существующий каталог, закройте приложение. В свойствах папки проверьте раздел «Безопасность», включая разрешения на отдельных файлах и в `backups`. Сохраните владельцу доступ для чтения и записи с наследованием дочерними папками и файлами. Удаление лишних прав на каталог не отзывает ранее скопированные данные. Новая установка использует отдельный каталог в LocalAppData.

Проверка выполняется встроенным Windows PowerShell от текущего пользователя, с системным путём из HKLM, без загрузки профиля пользователя. При запрете его запуска политикой Windows приложение выдаёт ошибку до открытия календаря. Входящие сетевые сообщения не запускают PowerShell. На обычном пути сохранения события используется атомарная запись внутри проверенной папки.

## macOS

Владельцем папки должен быть текущий пользователь. Обычный режим каталога — `0700`, файлов календаря — `0600`. Приложение проверяет дополнительные ACL, включая старые копии и файлы перед восстановлением. Разрешающие ACL на родительских каталогах также требуют проверки. Профиль в каталоге, который может подменить другой пользователь, не открывается. Для своих обычных файлов внутри приватной папки приложение сужает прежние разрешения чтения. Если файл при этом имеет ещё одну жёсткую ссылку или доступен посторонним для записи, нужна ручная проверка.

## Что защищает диск

Содержимое профиля и резервных копий сохраняется в JSON. Защита от чтения выключенного компьютера зависит от FileVault или BitLocker. Программа, работающая с правами владельца профиля, может получить доступ к его содержимому. При копировании резервной копии в другое место проверьте шифрование носителя и права нового каталога.

## Проверено

На macOS проверены миграция прежних разрешений, сохранность содержимого резервной копии и исходного файла восстановления, отказ на внешнюю жёсткую ссылку с открытыми правами и отказ для отдельного разрешающего ACL при закрытых POSIX-правах. На Windows 11 ARM64 (10.0.22621) проверены создание и повторное открытие профиля, штатная резервная копия, отказ на разрешение чтения Everyone для отдельного файла копии и отказ до создания календаря в доступной всем папке. Тесты используют собственные временные папки.

```sh
cargo test --release --locked --test storage_permissions
```
