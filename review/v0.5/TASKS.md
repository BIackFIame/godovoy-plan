# Большой список «Мои задачи» в 0.5.3

Экран строит интерактивные строки для видимой области списка. Индекс групп и открытых пунктов готовится при первом открытии страницы или при изменении снимка календаря. Контролы продолжают использовать ID события и пункта. Большие счётчики убраны из компактной навигации, а точное количество видно на странице и в баннере напоминаний.

## Замер на macOS

Для обеих оптимизированных сборок использовали одно окно 1040 × 630 и один синтетический профиль с 1 800 событиями и 21 600 открытыми пунктами. В каждой версии записали 16 кадров после четырёх прогревочных. Заменили системное уведомление тестовым обработчиком, чтобы не отправлять уведомление на рабочий стол.

| Версия | Медиана подготовки списка | p95 |
| --- | ---: | ---: |
| 0.5.2 | 80,66 мс | 85,90 мс |
| 0.5.3 | 0,04 мс | 0,05 мс |

Замер охватывает построение виджетов страницы после загрузки индекса. В замер не вошли запуск приложения, запись файла, работа GPU и сеть. Производительность старого оборудования этим прогоном не подтверждена.

## Функциональная проверка

- На macOS прокрутили список до последней группы и нажали последний чекбокс через тестовый ввод egui. В файле сохранилась отметка нужного пункта.
- Проверили порядок одинаковых сроков, исключение выполненных пунктов и сохранение группы без чек-листа. Прошли Rust-тесты и Clippy.
- Собрали универсальную macOS-версию и Windows-сборки x86, x64 и ARM64. Запуск в Windows не проверялся.
