# Интерфейс «Годового плана» 0.3

## Что поменялось

| Сценарий | Изменение |
| --- | --- |
| Просмотреть год | Светлая навигация, крупный заголовок и одно основное действие. Круг показывает месяцы, текущую дату и категории, которые различаются формой и цветом. |
| Найти событие | Выбор года, режима и фильтра собран над календарём. Поиск понимает разные регистры и варианты «е» / «ё». У выбранной строки заметная рамка, а дата стоит у правого края. |
| Подготовить событие | Дата и ответственный находятся в верхней карточке. Чек-лист показывает число выполненных пунктов, начало подготовки и дедлайны, в том числе текстовую метку просрочки. |
| Редактировать событие | Диалог отделён от фона. Он показывает календарные даты, рассчитанные по введённым срокам. Диалог закрывается явной кнопкой или Escape. |
| Записать итог | При переключении между событиями в открытом приложении сохраняется несохранённый черновик заметки. |

## Проверки читаемости

Контраст основных пар рассчитан по формуле относительной яркости. Основной текст на белом имеет соотношение 15,53:1, второстепенный текст на фоне — 6,31:1, белый текст основной кнопки — 6,42:1. У подписей категорий на соответствующих подложках диапазон от 5,53:1 до 6,61:1. Ориентир для обычного текста — 4,5:1. [W3C WCAG 2.2, Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

Интерфейс передаёт названия контролов через AccessKit. Полный прогон с VoiceOver, проверка экранного диктора Windows и пользовательское тестирование остаются за рамками визуальной проверки.

Для текста используется Golos Text, шрифт включён в приложение и доступен без сети. Лицензия лежит в `assets/OFL-Golos-Text.txt`. [Проект Golos Text](https://github.com/googlefonts/golos-text)
