# Проверка безопасности «Годового плана» 0.2

Проверка началась с независимого статического анализа версии 0.1. Ниже указано, какие наблюдения закрыты изменениями и что осталось в границах доверия. Проект и тесты используют вымышленные данные.

| Что проверили | Что изменилось в 0.2 |
| --- | --- |
| Сессии локальной синхронизации | Общий срок сессии 6 секунд, максимум восемь обработчиков и не больше трёх на IPv4-адрес. При паузе ранее начатые сессии отменяются на операциях ввода-вывода. При завершении фоновые потоки закрываются и ожидаются. |
| Рост реплики и задержки интерфейса | Валидация полей и вложенных коллекций до записи. Предел итогового профиля 8 МиБ, ограниченная сериализация исходящего снимка, атомарная запись. Интерфейс читает снимок через `Arc` и размещает маркеры круга за один проход. |
| Счётчики версий и приглашения | Скачки счётчика отклоняются. Если отправитель зарегистрировал устройство, а получатель не успел сохранить ответ, новое приглашение от того же отправителя может восстановить подключение для прежней идентичности. |
| HTTP API | По умолчанию выключен, привязан к `127.0.0.1`. Токен импорта ограничен методом загрузки. Можно сменить токены и сразу закрыть порт. Для HTTP ограничены тело, заголовки, время и число подключений. |
| Изоляция профилей и моста | Два процесса с разными профилями получают разные идентичности. Один профиль блокируется для второго экземпляра приложения. Мост запускается отдельным процессом и обращается к данным через API. Новые каталоги профиля на Unix создаются с правами `0700`. |

## Проверки на macOS

- Два отдельных процесса проверили конкуренцию за один профиль и независимость разных профилей.
- Отдельный процесс Rust-моста забрал JSON с тестового сервера. Токен источника ушёл источнику, токен импорта работал только на локальном API. Повтор импорта сохранил идентичность события. Неверный пакет не оставил частичных изменений.
- Сценарий из 400 обновлений и 400 чтений сохранил одну запись. После остановки фоновой службы порт освободился. Штатная утилита `leaks --atExit` показала **0 утечек** в этом тестовом процессе и отдельно в тесте LAN-синхронизации.
- Локальная проверка `Cargo.lock` по базе RustSec не обнаружила опубликованных уязвимостей. Есть предупреждение о статусе поддержки используемой версии `chrono`. [RUSTSEC-2026-0543](https://rustsec.org/advisories/RUSTSEC-2026-0543)

## Границы проверки

Участники локального пространства по-прежнему доверенные. Общий ключ Noise защищает канал, а подписи авторов каждой записи и отзыв отдельного устройства пока не предусмотрены. Обнаружение раскрывает технические идентификаторы внутри локального сегмента. Профиль защищён правами ОС и содержит ключи. Другие программы с правами того же пользователя ОС потенциально могут прочитать профиль. Отдельный процесс моста ограничен токеном при обращении к API, дополнительная песочница ОС ему не назначается.

Проверка памяти покрывала тестируемые сценарии API и LAN на Mac. Длительная работа интерфейса и профилирование памяти в Windows не проверялись. Windows-бинарники собраны, их запуск и совместный обмен с Mac в этой проверке не выполнялись.
