Годовой план

Панель администратора

Введите временный ключ из окна, в котором вы запустили панель.

Защита данных

Настройки действуют для всех сотрудников и ключей этого серверного календаря.

Профили защиты

Выберите требования, которые применяет ваша организация. Можно включить оба профиля.

Исключения

При первом включении профиля оба разрешения выключены.

Вы выключаете последний профиль

Снова станут доступны описания, дневник и удалённый вход по ключам с таким разрешением.

Сведения организации

Эти поля заполняют для отчёта. Профили можно включить и без них. Используйте должность, рабочий контакт и номера внутренних документов. Пароли и ключи храните отдельно.

Сотрудники

Исправьте имя в рабочем реестре или отзовите все действующие ключи одного сотрудника.

    Подключение ИИ по MCP

    Помощник видит только события, назначенные этому сотруднику. Подключайте модель, которой компания разрешила передавать календарные данные.

    Сохраните ключ в настройках подключения. После закрытия карточки он будет скрыт.

    Место на диске для срочного отзыва

    Сервер может заранее выделить 2 МиБ для отзыва ключей при нехватке места. После использования резерв можно подготовить снова.

    Резервная копия

    Сервер сохранит снимок календаря в каталоге, который администратор указал при запуске панели, и проверит сохранённую копию.

    Чтобы выбрать каталог, запустите на сервере godovoy-online configure DIR --backup-root PATH.

    Отчёт для проверки

    Сервер соберёт действующие настройки и сохранённые сведения организации. Выберите, кому передавать скачанный файл.

    Посмотреть показатели сервера
    Что проверяет сама организация
    • Определяет состав данных, цели и правовые основания обработки, назначает ответственных.
    • Проверяет размещение серверов и копий, доступ сотрудников, сроки хранения и удаление данных.
    • Оценивает применимость уведомлений, аттестации и требований к средствам защиты для своей системы.

    Отчёт фиксирует настройки календаря. Заключение о соблюдении требований оформляет организация по результатам своей проверки.
