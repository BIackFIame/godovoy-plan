# Программная отрисовка годового календаря в Windows

Этот комплект нужен для виртуальной машины или компьютера, где окно календаря завершается с сообщением об отсутствии OpenGL 2.0. Mesa Softpipe рисует окно на процессоре. При наличии рабочего видеодрайвера используйте обычный архив приложения.

1. Возьмите комплект с той же архитектурой, что и файл godovoy-plan.exe. Для 32-разрядного приложения нужен x86, даже если сама Windows 64-разрядная.
2. Закройте календарь. Скопируйте файлы opengl32.dll и libgallium_wgl.dll в отдельную папку приложения рядом с godovoy-plan.exe. Проверьте SHA-256 по ведомости выпуска. Для просмотра хеша в PowerShell используйте Get-FileHash.
3. Запустите godovoy-plan.exe. Для возврата к аппаратной графике закройте программу и уберите из её папки эти два файла.

Системные каталоги Windows и реестр для такой установки не используются. Сервер godovoy-online.exe работает без графического комплекта.

## Состав и сборка

Библиотеки собраны из неизменённых исходников Mesa 26.3.1 с программным драйвером Softpipe, статической средой исполнения C и отключённым LLVM. Лицензионные уведомления включены в Mesa-license.rst и licenses. Скрипт сборки расположен в packaging/windows/test-renderer.ps1 в репозитории календаря.
