# Годовой план для Android

APK устанавливается на Android 8.0 и выше с процессором ARMv7, ARM64 или x86-64. Календарь работает без учётной записи в интернете. Вкладка «Год» показывает месяцы, события и сроки. В центре годового круга можно сбросить выбранный месяц. В карточке события можно отметить пункт, оставить запись в дневнике или изменить повторение.

## Связь с командой

В новом приложении нажмите «Присоединиться» и передайте коллеге запрос своего устройства. Коллега открывает «Доступ» → «Пригласить устройство», вставляет запрос и возвращает код. Введите код и своё имя. При необходимости укажите IPv4-адрес и порт из вкладки «Доступ» коллеги. Оба приложения должны быть открыты и доступны друг другу по сети. Сворачивание мобильного клиента приостанавливает сетевой обмен.

В той же вкладке можно перенести зашифрованный файл календаря через системный выбор документов. Открывать его следует на устройстве, которое уже подключено к той же команде и использует действующий ключ. Личные ключи, профиль и файлы подготовки обмена хранятся в приватном каталоге приложения, исключённом из системного резервного копирования. Сохранённые пользователем и ранее переданные данные остаются на соответствующих устройствах.

Локальные уведомления включаются во вкладке «Напоминания». Приложение обновляет график на следующие 60 дней при открытии и после получения изменений. На заблокированном экране показывается общее приглашение открыть календарь. Настройки энергосбережения и уведомлений Android могут изменить фактическое время доставки.

## Сборка APK

Нужны JDK 17 или новее, Rust 1.94 с целями `aarch64-linux-android`, `armv7-linux-androideabi` и `x86_64-linux-android`, Android SDK Platform 34, Build Tools 35.0.0, Android NDK r28, утилиты `zip` и `xargs`. Исходный файл `Cargo.lock` находится в `mobile/core`.

```sh
rustup target add aarch64-linux-android x86_64-linux-android armv7-linux-androideabi
export JAVA_HOME=/path/to/jdk
export ANDROID_HOME=/path/to/android-sdk
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/28.0.12674087"
export MOBILE_BUILD_DIR="$PWD/build/android"
sh mobile/android/build.sh
```

Итоговый `GodovoyPlan-Android.apk` содержит все три ABI. Скрипт сохраняет локальный тестовый ключ в каталоге сборки. Для собственных обновляемых релизов передайте `ANDROID_SIGNING_KEYSTORE`, `ANDROID_SIGNING_ALIAS` и `ANDROID_SIGNING_PASSWORD` из защищённого окружения. Android требует одинаковую подпись для установки обновления поверх существующей версии.
