# Годовой план для iPhone и iPad

Нативный интерфейс на SwiftUI использует то же локальное ядро Rust, что и настольная версия. Минимальная версия системы — iOS или iPadOS 16. На Mac с Apple Silicon проект также собирается для симулятора ARM64.

## Установка и сборка

Архив Xcode содержит проект и две готовые статические библиотеки Rust. Откройте `GodovoyPlan.xcodeproj`, выберите схему `GodovoyPlan` и устройство. Для установки на физическое устройство выберите свою Team в Signing & Capabilities, подключите iPhone или iPad и нажмите Run. Apple должна разрешить подпись для выбранного идентификатора приложения. Для управляемой установки в компании потребуется подпись и способ распространения, одобренный администратором.

На Mac с установленными и настроенными Xcode и iOS Simulator следующая команда собирает Release-приложения для симулятора и устройства. Вариант для устройства на этом шаге выпускается без подписи.

```sh
./build.sh --prebuilt
```

Собранные пакеты находятся в `build/Xcode/Build/Products/Release-iphonesimulator/` и `Release-iphoneos/`. Для проверки создания команды и сохранения события выберите UDID установленного симулятора через `xcrun simctl list devices available` и передайте его команде `./build.sh --prebuilt --test UDID`. Тест использует отдельный профиль в Debug-конфигурации.

В полном дереве исходников для пересборки Rust нужен Rust 1.94 или совместимая более новая версия. В каталоге `mobile/ios` выполните следующие команды.

```sh
rustup target add aarch64-apple-ios aarch64-apple-ios-sim
./build.sh
```

Для сборки только библиотек выполните `./build.sh --core-only`. Если Xcode запрашивает принятие пользовательской лицензии, её может просмотреть владелец Mac командой `sudo xcodebuild -license`. Проект уже сгенерирован. После изменения перечня файлов его можно обновить командой `xcodegen generate`.

## Работа в команде

Чтобы создать календарь, укажите своё имя и название команды. Кнопка «+» открывает новое событие. Укажите дату, повторение, ответственного и сроки подготовки. Нажатие на месяц годового круга фильтрует список. Чек-лист и заметка открываются из карточки события. Сотрудник видит назначенные ему события во вкладке «Мои задачи». Разрешение на локальные уведомления можно включить во вкладке «Обмен».

Для подключения к существующей команде выберите «Присоединиться» и скопируйте запрос устройства. Владелец календаря вставляет запрос в «Обмен → Пригласить коллегу» и передаёт код вам. Откройте приложения в одной локальной сети и разрешите доступ к ней в iOS. Если соединение по адресу из приглашения недоступно, раскройте «Указать адрес вручную» и введите IPv4 и порт с экрана обмена коллеги. Если адрес устройства сменился, его можно обновить через «Обмен → Подключить по адресу». Приложение синхронизируется при открытом экране. В фоне доставку запланированных напоминаний выполняет iOS.

У уже подключённых устройств обмен зашифрованным пакетом `.yrplan` работает через «Файлы» и системное меню «Поделиться», включая AirDrop, если он доступен. Выберите «Импортировать .yrplan» на принимающей стороне. Пакет предназначен для календаря с текущим ключом.

На устройстве профиль хранится в приватном Application Support с системной защитой файлов при блокировке и исключением из резервных копий. При уходе приложения с переднего плана скрывается содержимое экрана. Скопированные приглашения ограничены этим устройством и сроком 15 минут. При отзыве доступа управляющее устройство меняет ключ команды. Полученные ранее материалы могут сохраниться у бывшего участника и в сделанных им копиях.
