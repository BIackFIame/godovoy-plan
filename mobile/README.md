# Годовой план на телефоне

Android и iPhone используют тот же календарь, формат обмена и Rust-код синхронизации, что и настольная версия 0.5.41. Интерфейс Android написан на Java с системными виджетами, интерфейс iPhone и iPad — на SwiftUI. Для работы календаря достаточно телефона. Для сетевого обмена два устройства должны иметь доступ друг к другу по локальной сети.

## Подключить телефон к существующему календарю

1. Подключите телефон и компьютер к одной локальной сети. Откройте приложение на обоих устройствах.
2. На новом телефоне выберите присоединение и скопируйте запрос устройства. Передайте его человеку, который выдаёт доступ. При наличии управляющего компьютера выдавайте приглашение с него.
3. На компьютере откройте «Синхронизация», вставьте запрос и создайте приглашение. Передайте код лично владельцу телефона. На телефоне укажите своё имя и вставьте ответный код. Держите приложение открытым до появления календаря.
4. Если устройства не находят друг друга, укажите на телефоне IPv4-адрес и порт из окна синхронизации компьютера. На iOS разрешите доступ к локальной сети. Для iOS предусмотрено прямое подключение по адресу из приглашения или адресу, введённому вручную. В гостевой сети Wi-Fi администратор может запретить соединения между клиентами.
5. Откройте нужный месяц на круге года. В карточке события можно изменить ответственного, дату и чек-лист. Для ежегодного события выбирайте область изменения — только выбранный год или с выбранного года. У каждого года свои отметки выполнения и заметки.

Если сети между устройствами нет, участник может сохранить зашифрованный файл обмена `.yrplan`. Передайте файл через системное приложение, AirDrop или внешний накопитель и импортируйте его в уже подключённый календарь того же поколения ключа. Первичное подключение по приглашению требует сетевого соединения.

## Один сотрудник на нескольких устройствах

Подключите компьютер и телефон к одному календарю. На устройстве с правом управления откройте **Доступ** (Android) или **Обмен** (iPhone), затем **Связать устройства сотрудника**. Выберите подключённое устройство по его ID и укажите сотрудника, чей список задач должен на нём открываться. Два человека с одинаковым именем останутся разными участниками, пока вы сами не создадите связь.

После обмена изменениями назначения, существующие чек-листы и напоминания сотрудника видны на обоих устройствах. Разрешение на системные уведомления включается на каждом устройстве отдельно. Чтобы снова разделить назначения, выберите **Устройство отдельно**. Доступ к потерянному телефону отзывается отдельно в списке устройств. Связи между устройствами поддерживаются начиная с версии 0.5.42. Для одинакового списка задач на телефоне и компьютере обновите оба приложения.

## Личные напоминания

Назначьте себя ответственным и укажите, за сколько дней начать подготовку. Разрешите уведомления на телефоне. Календарь составляет расписание на 60 дней вперёд и обновляет его, пока приложение открыто. В один день приходит одно общее напоминание. Подробности доступны в приложении. Расчёт использует местный часовой пояс и ориентируется на 09:00. Фактическое время доставки зависит от системы, режима фокусирования и энергосбережения. Если приложение долго было закрыто, откройте его для получения свежих назначений и обновления расписания.

## Уход сотрудника

На управляющем устройстве отзовите **все** устройства сотрудника, включая его телефон и компьютер. Передайте новые приглашения оставшимся коллегам. Дальнейшие рабочие изменения вносите в календарь с новым ключом. Устройство со старым ключом сохраняет ранее полученное содержимое, включая собственные выгрузки. Оно также может обмениваться данными со старыми копиями, пока их владельцы не перешли на новый ключ. Подробнее в [инструкции по отзыву](../review/v0.5/DEVICE-ACCESS.md).

Профиль на телефоне хранится в каталоге приложения. На Android это приватное хранилище с исключением из резервного копирования. Проект iOS использует защиту файлов устройства и исключение профиля из резервного копирования. Для защиты потерянного телефона важен системный код блокировки. Файлами, которые пользователь сам сохранил за пределами приложения, распоряжается владелец устройства.

## Сборка

Общий компонент собирается Rust 1.94 или новее. Зависимости Rust зафиксированы в Cargo.lock. Инструменты и зависимости требуются на машине сборки. Для тестов общего кода на компьютере выполните из корня проекта:

```sh
cargo test --manifest-path mobile/core/Cargo.toml --locked
```

Сетевые тесты требуют разрешения на локальные TCP-соединения. Команды платформенной сборки и проверки устанавливаемых пакетов приведены в каталогах [Android](android/) и [iOS](ios/). Описание границы между Rust и нативным интерфейсом находится в [контракте мобильных клиентов](PROTOCOL.md).
